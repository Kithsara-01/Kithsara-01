### ⚡ Electra — Online Electronics E-Commerce Platform

A full-stack electronics retail platform built on the MERN stack, featuring a customer-facing storefront and a dedicated admin dashboard for managing products, orders, stock, and revenue.

**Highlights:**
- 🎨 Custom flat design system — no shadows, no gradients, teal accent (`#2FA084`) with a clean slate text hierarchy
- 📊 Admin dashboard with order management, stock tracking, and revenue analytics
- 🔍 Server-side search, filtering, and pagination for users and orders
- 💳 Payment integration via PayHere sandbox

**Tech Stack:** MongoDB · Express.js · React · Node.js · Tailwind CSS
